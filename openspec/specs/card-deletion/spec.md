# card-deletion Specification

## Purpose
Позволяет пользователю удалить карточку с канбан-доски: подтвердить действие, после успешного удаления карточка пропадает с доски без перезагрузки страницы, сохранить удаление после перезагрузки страницы.

## Requirements

### Requirement: Элемент управления для удаления карточки

Каждая карточка, отображаемая на доске, SHALL иметь видимый элемент управления для удаления.

#### Scenario: Элемент управления виден на всех карточках

- **WHEN** на доске отображаются три карточки
- **THEN** у каждой карточки есть видимый элемент управления для удаления

### Requirement: Подтверждение перед удалением

Система SHALL требовать подтверждения пользователя перед удалением карточки с доски.

#### Scenario: Пользователь подтвердил удаление

- **WHEN** пользователь активировал элемент управления удаления и подтвердил действие
- **THEN** карточка удаляется с доски

#### Scenario: Пользователь отменил удаление

- **WHEN** пользователь активировал элемент управления удаления и отменил действие
- **THEN** карточка остаётся на доске, ничего не меняется

### Requirement: Удаление без перезагрузки страницы

Система SHALL удалять подтверждённую карточку из интерфейса без перезагрузки страницы, при этом все остальные карточки остаются на своих местах.

#### Scenario: Удалена последняя карточка — доска показывает пустую колонку

- **WHEN** пользователь подтверждает удаление последней карточки на доске
- **THEN** карточка исчезает, а колонка показывает пустое состояние без ошибок

#### Scenario: Удалена одна из трёх карточек

- **WHEN** на доске три карточки, пользователь подтверждает удаление одной
- **THEN** на доске остаются две другие карточки на своих местах

### Requirement: Удаление сохраняется после перезагрузки

Система SHALL сохранять удаление так, чтобы удалённые карточки не возвращались после перезагрузки страницы.

#### Scenario: Удалённая карточка не возвращается после перезагрузки

- **WHEN** пользователь удалил карточку, а затем перезагрузил страницу
- **THEN** удалённая карточка не появляется на доске заново

### Requirement: Обработка ошибки при неудачном удалении

Система SHALL оставить карточку на доске и показать пользователю сообщение об ошибке, если удаление не удалось.

#### Scenario: Сервер недоступен или вернул ошибку

- **WHEN** удаление не удалось, потому что сервер недоступен или вернул ошибку
- **THEN** карточка остаётся на доске, пользователь видит сообщение об ошибке

### Requirement: Удаление выполненной карточки

Система SHALL позволять удалять выполненные карточки тем же механизмом, что и обычные.

#### Scenario: Удаление выполненной карточки

- **WHEN** пользователь активировал удаление выполненной карточки и подтвердил действие
- **THEN** выполненная карточка удаляется с доски так же, как обычная
