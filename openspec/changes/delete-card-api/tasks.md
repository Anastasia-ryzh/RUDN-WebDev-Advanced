# Tasks: delete-card-api

## 1. Реализовать роут DELETE /cards/:id

**Файл:** `server/index.ts`

**Что сделать:**

- Добавить `app.delete("/cards/:id", ...)` после существующих роутов (`GET /cards`, `POST /cards`)
- Извлечь `id` из `req.params.id`
- Найти карточку через `cards.findIndex(c => c.id === req.params.id)`
- Если не найдена (`index === -1`) — вернуть `res.status(404).json({ error: "Карточка не найдена" })` и `return`
- Если найдена — удалить через `cards.splice(index, 1)` и вернуть `res.status(204).end()`

**Критерии приёмки:**

- [ ] `DELETE /cards/1` с существующим id → статус 204, тело пустое
- [ ] `DELETE /cards/999` с несуществующим id → статус 404, тело `{"error": "Карточка не найдена"}`
- [ ] После удаления `GET /cards` не возвращает удалённую карточку

## 2. Реализовать JSON-обработчик 404 для неизвестных адресов

**Файл:** `server/index.ts`

**Что сделать:**

- Добавить `app.use((req, res) => { res.status(404).json({ error: "Not found" }); })` **после всех роутов**, но **перед** error-middleware
- Этот обработчик перехватывает все запросы к несуществующим маршрутам
- Возвращает JSON, а не HTML

**Критерии приёмки:**

- [ ] Запрос на любой неизвестный маршрут (например `DELETE /unknown`) → статус 404, тело JSON
- [ ] Ответ не содержит HTML

## 3. Реализовать error-middleware для 500

**Файл:** `server/index.ts`

**Что сделать:**

- Добавить `app.use` с функцией-обработчиком **после catch-all 404**
- Сигнатура: `(err: Error, req: express.Request, res: express.Response, next: express.NextFunction) => { ... }`
- Явные типы всех четырёх параметров обязательны для `tsc --noEmit` в strict-режиме
- Ответ: `res.status(500).json({ error: "Внутренняя ошибка сервера" })`

**Критерии приёмки:**

- [ ] `tsc --noEmit` в `server/` проходит без ошибок типов
- [ ] При выбросе исключения в любом роуте — статус 500, тело JSON
