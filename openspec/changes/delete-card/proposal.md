## Why

На доске отсутствует возможность удалять карточки — ни ошибочно созданные, ни просто ненужные. Однажды добавленная карточка остаётся на доске навсегда, что ограничивает функциональность канбан-интерфейса.

## What Changes

- У каждой карточки есть элемент управления для удаления
- Перед удалением пользователь подтверждает действие
- Удалённая карточка пропадает с доски без перезагрузки
- Удалённая карточка не возвращается после перезагрузки страницы
- Если сервер вернул ошибку, карточка остаётся на доске и пользователь видит сообщение

## Capabilities

### New Capabilities

- `card-deletion`: Возможность удаления карточки с доски с подтверждением пользователя

## Impact
