## Why

После переезда на собственный Express-сервер перестала работать удаление карточек: клиент отправляет `DELETE /api/cards/<id>`, прокси Vite транслирует это в `DELETE /cards/<id>`, но на сервере нет обработчика этого маршрута. Express возвращает встроенный 404 с HTML-телом, а клиент ожидает JSON и проверяет `response.ok`. В результате — 404 HTML вместо JSON, клиент бросает generic-ошибку, карточка не удаляется.

## What Changes

- Добавить обработчик `DELETE /cards/:id` в `server/index.ts`, который удаляет карточку по `req.params.id` и отвечает `204 No Content` без тела.
- Добавить обработчик удаления несуществующей карточки: `404` + JSON `{"error": "..."}`.
- Добавить catch-all 404-обработчик, который возвращает JSON (не HTML) для любого неизвестного маршрута.
- Добавить error-middleware (четыре параметра: `err, req, res, next`) для возврата `500` + JSON при неожиданных ошибках.
- Error-middleware и 404-обработчик регистрируются после всех роутов.

## Capabilities

### New Capabilities
- `card-deletion-api`: серверная API-спецификация для удаления карточек — маршруты, статус-коды, форматы ответов, обработка ошибок.

## Impact

- **Код:** `server/index.ts` — добавление роута `DELETE /cards/:id`, catch-all 404, error-middleware.
- **Клиент:** ни одного файла в `client/` не меняется — `deleteCard` уже проверяет только `response.ok`.
- **Зависимости:** нет новых зависимостей, только Express-встроенные middleware.
- **Системы:** только сервер Express (`server/index.ts`); база данных — переменная в памяти, без изменений.
